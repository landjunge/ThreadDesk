ThreadDesk bewahrt Projektkontext, Threads, Notizen und Arbeitsstände lokal. Es führt keine externen Agenten selbst aus. Die veröffentlichten Desktop-Versionen können einen anderen Funktionsstand als der aktuelle Quellcode haben.

Die fünf Installationsvarianten werden automatisch angezeigt. Nur tatsächlich veröffentlichte Installationsdateien sind anklickbar. Fehlende Pakete erscheinen als **In Vorbereitung**.

| Plattform | Status |
| --- | --- |
| macOS Intel | Veröffentlicht: [ThreadDesk 0.2.0](https://github.com/landjunge/ThreadDesk/releases/tag/v0.2.0) |
| macOS Apple Silicon | In Vorbereitung – kein bestätigter Installer |
| Windows Desktop | In Vorbereitung – kein bestätigter Installer |
| Linux Desktop | In Vorbereitung – kein bestätigter Installer |
| Debian Server | In Vorbereitung – kein bestätigter Server-Installer |

Die Platzhalter sind keine Downloads. Nach Veröffentlichung eines passenden Pakets ersetzt die Automatik den jeweiligen Platzhalter durch einen Download-Button.

## Einstieg und Dokumentation

Die ausführliche Projektdokumentation, Entwicklungsdetails und Installationshinweise befinden sich in der [Haupt-README](README.md) und im Verzeichnis [docs](docs). Die aktuelle Desktop-Ausgabe und der Entwicklungsstand sind getrennt zu betrachten.
